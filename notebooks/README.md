# Notebooks

This directory contains the main experimental workflow used in the bachelor thesis project.

The notebooks are organized in execution order, following the same logic as the thesis workflow: data preparation, baseline models, stability experiments, quality control, leakage checks, leakage-free splits and final model reporting.

---

## Notebook Order

| Notebook | Purpose |
|---|---|
| `01_data_prep.ipynb` | Prepares the datasets and creates stratified train / validation / test splits. |
| `02_data_and_baselines.ipynb` | Trains baseline models for tabular and image datasets. |
| `03_experiments_stability.ipynb` | Runs stability experiments using multiple random seeds and additional tuning experiments. |
| `04_qc_and_leakage.ipynb` | Performs image quality control and exact duplicate leakage detection using MD5 hashes. |
| `05_leakage_free_split.ipynb` | Creates leakage-free dataset splits by grouping duplicate images. |
| `06_rerun_baseline_v2.ipynb` | Re-runs selected baselines on leakage-free splits. |
| `07_final_registry_and_models.ipynb` | Builds the final dataset registry and final result summaries. |

---

## Recommended Setup

Before running the notebooks, install the project dependencies from the repository root:

```bash
pip install -r requirements.txt
```

Then configure Kaggle API access and download the datasets:

```bash
python scripts/download_kaggle_data.py
```

To verify that the raw data was downloaded correctly, run:

```bash
python src/scan_raw.py
```

You can also verify only one dataset:

```bash
python src/scan_raw.py --dataset thyroid_recurrence
```

## Expected Local Data Structure

The notebooks expect the following local data structure:

```text
Data/
├── raw/
├── curated/
├── curated_qc/
└── curated_v2/
```

The `Data/` directory is ignored by Git and should not be committed.

---

## Execution Order

Run the notebooks in numerical order:

```text
01 → 02 → 03 → 04 → 05 → 06 → 07
```

Each notebook depends on outputs generated by previous steps.

For example:

- `02_data_and_baselines.ipynb` expects prepared splits from `01_data_prep.ipynb`
- `04_qc_and_leakage.ipynb` expects existing curated splits
- `06_rerun_baseline_v2.ipynb` expects leakage-free splits from `05_leakage_free_split.ipynb`
- `07_final_registry_and_models.ipynb` summarizes the final results

---

## Generated Outputs

The notebooks generate local outputs such as:

```text
Data/curated/
Data/curated_qc/
Data/curated_v2/
Runs/
artifacts/
```

These outputs are not committed to GitHub because they can be regenerated and may be large.

## Notes

The goal of these notebooks is to make the thesis workflow transparent and reproducible.

They are intended to show:

- how the datasets were prepared,
- how baseline models were trained,
- how stability was checked,
- how quality control was performed,
- how data leakage was detected,
- how leakage-free splits were created,
- how final results were summarized.

The reported thesis results are summarized in the main repository `README.md`.
